How a project runs

The same five steps whether it is a two-week design job or a two-year platform.

  1. You bring the project

    A call, a referral or an email. We start with what you want to build and why.

  2. Scope, proposal, design

    A written scope and quote, then UX, UI and graphics you sign off before code starts.

  3. Build

    Web, mobile, backend and AI. You see progress as it happens, not at the end.

  4. Deploy and deliver

    Cloud setup, handover and documentation. It runs on infrastructure you own.

  5. Maintain

    A fixed monthly fee for support and updates. Cloud costs pass through at cost.
